# samiylushiyperesil — копировщик торговых сигналов

Читает закрытый канал с вашего аккаунта (Telethon), переписывает сигналы в свой формат
и публикует в ваш канал через бота. Голосовые, фото, видео и прочие сообщения не копируются —
только сигналы, тейки, стопы и перевод в безубыток.

* сигнал → `#GOLD SHORT ⬇️`, вход = середина диапазона, R на каждый TP = (R позиции, округлённый) / число тейков
* `✅TP1 - 4014 XAUUSD` → `🔥 TP1 взят - 4014 GOLD, +0.11R` (ответом на ваш пост)
* сообщение про безубыток → `переставляем стоп-лосс в безубыток на точку входа 4019`
* `🚨 Отстопило` → `🚨 сработал стоп-лосс. -1R` (если после тейков был БУ — `0R`, если БУ не было — минус по оставшимся ордерам)
* 23:40 МСК — итоги дня в канал; сигналы без единого ответа считаются отменёнными, через 10 минут на них приходит «отменяем ордера по этой позиции»
* пятница — недельная статистика админу в личку, последний день месяца — месячная
* команды админа боту: `/today`, `/week`, `/month [09.2026]`, `/period 01.10.2026 26.10.2026`, `/open`

## Панель и три источника

Команда `/panel` в личке бота: для каждого источника выбирается канал-источник (из каналов аккаунта)
и канал-приёмник (бот должен быть в нём админом). При первом запуске источник 1 берёт каналы из
`SOURCE_CHANNEL` / `TARGET_CHANNEL` в `.env`. Источник 3 пока заглушка.

### Источник 2 — Forex Bulls Vip Trades

* `BUY XAUUSD / SL 4019.957 / TP 4068.642` → заголовок (текст задаётся в панели), `#GOLD LONG`,
  `Вход <цена FxPro>`, `SL: 4019.96`, `Takeprofit: 4068.64` и строка со ссылкой на бота
* реплай `Close off profits` → `закрываем сделку в профит по текущей цене. +X% к депозиту`,
  X = 1% × |цена − вход| / |вход − SL|
* реплай `BUY XAUUSD AGAIN NOW` → на старый сигнал «сработал стоп-лосс», затем новый сигнал
  с входом по текущей цене и прежними SL/TP
* прочие реплаи на сигнал переводятся на русский через Claude API (`ANTHROPIC_API_KEY`)
* медиа, ссылки, приветствия и всё, что не сигнал и не реплай на сигнал, не копируется

Цена берётся у FxPro через cTrader Open API: нужен счёт FxPro cTrader (можно демо) и приложение
на openapi.ctrader.com → `CTRADER_*` в `.env`. Для BUY берётся ask, для SELL — bid. Пока доступа нет,
бот пишет «Вход по рынку» и предупреждает админа; цены других брокеров не подставляются.

## Установка на сервер

```bash
git clone https://github.com/bingxcourt-cmyk/induk-lichkanegrA.git /opt/signalbot
cd /opt/signalbot && bash install.sh
```
и далее по подсказкам установщика. Админ должен один раз нажать /start в боте, чтобы бот мог писать в личку.

Проверка логики без Telegram: `python3 tests/test_flow.py` и `python3 tests/test_source2.py`
