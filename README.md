# samiylushiyperesil — копировщик торговых сигналов

Читает закрытый канал с вашего аккаунта (Telethon), переписывает сигналы в свой формат
и публикует в ваш канал через бота. Голосовые, фото, видео и прочие сообщения не копируются —
только сигналы, тейки, стопы и перевод в безубыток.

* сигнал → `#GOLD SHORT ⬇️`, вход = середина диапазона, R на каждый TP = (R позиции, округлённый) / число тейков
* `✅TP1 - 4014 XAUUSD` → `🔥 TP1 взят - 4014 GOLD, +0.11R` (ответом на ваш пост)
* сообщение про безубыток → `переставляем стоп-лосс в безубыток на точку входа 4019`
* `🚨 Отстопило` → `🚨 сработал стоп-лосс. -1R` (если после тейков был БУ — `0R`, если БУ не было — минус по оставшимся ордерам)
* 23:40 МСК — итоги дня в канал; сигналы без единого ответа считаются отменёнными, через 10 минут на них приходит «отменяем ордера по этой позиции»
* пятница — недельная статистика админу в личку, последний день месяца — месячная
* каналы «откуда» и «куда» выбираются в боте: `/settings` → кнопки со списком ваших каналов (или прислать ID / @username / ссылку / переслать сообщение из канала), без перезапуска
* команды админа боту: `/settings`, `/today`, `/week`, `/month [09.2026]`, `/period 01.10.2026 26.10.2026`, `/open`

## Правила перенаправления

У каждого перенаправления в `/settings` → «📐 Правила» свои правила:

* **Стандарт (источник 1)** — всё, что описано выше
* **Forex Bulls (источник 2)** — канал Forex Bulls Vip Trades, золото и валютные пары (`#GOLD`, `#GBPJPY`…):
  * `BUY XAUUSD / SL 4019.957 / TP 4068.642` → заголовок («🏷 Заголовок сигнала» в боте), `#GOLD LONG`,
    `Вход <текущая цена>`, `SL: 4019.96`, `Takeprofit: 4068.64` и строка со ссылкой на бота
  * реплай `Close off profits` → `закрываем сделку в профит по текущей цене. +X% к депозиту`,
    X = 1% × |цена − вход| / |вход − SL|
  * реплай `BUY XAUUSD AGAIN NOW` → на старый сигнал «сработал стоп-лосс», затем новый сигнал
    с входом по текущей цене и прежними SL/TP
  * прочие реплаи на сигнал переводятся на русский через Claude API (`ANTHROPIC_API_KEY`)
  * медиа, ссылки, приветствия и всё, что не сигнал и не реплай на сигнал, не копируется
* **Заглушка (источник 3)** — пока ничего не копирует

Цена для Forex Bulls (для BUY — ask, для SELL — bid) берётся у FxPro через cTrader Open API:

1. Счёт FxPro cTrader (можно демо), привязанный к вашему cTrader ID.
2. openapi.ctrader.com → Applications → Add new app. После одобрения Client ID и Secret — в `.env`.
3. `venv/bin/python -m signalbot.ctrader_setup` — токены из Sandbox (scope «Account info»), выбор счёта FxPro.
4. `systemctl restart signalbot`. Токен бот обновляет сам (`data/ctrader_token.json`).

Пока cTrader не настроен, цена берётся у OANDA (`OANDA_TOKEN`) или Twelve Data (`TWELVEDATA_KEY`);
иначе бот пишет «Вход по рынку»
и предупреждает админа.

## Установка на сервер

```bash
git clone https://github.com/bingxcourt-cmyk/induk-lichkanegrA.git /opt/signalbot
cd /opt/signalbot && bash install.sh
```
затем впишите API_ID, API_HASH, BOT_TOKEN в .env и войдите в аккаунт-читатель:
```bash
systemctl stop signalbot; venv/bin/python -m signalbot.login; systemctl enable --now signalbot
```
Каналы выберите в боте командой /settings. Админ должен один раз нажать /start в боте, чтобы бот мог писать в личку.

Проверка логики без Telegram: `python3 tests/test_flow.py`, `python3 tests/test_rules1.py` и `python3 tests/test_source2.py`

## Индикатор #1 — независимая статистика Aurum Research Club

`/indicator` или кнопка «Индикатор #1» в `/settings`: сегодня, вчера, неделя,
месяц, вся доступная история и произвольный период. Можно написать
`/indicator 01.10.2026 05.11.2026`. Под отчётом — список сигналов с максимальным
тейком и ссылками на исходные публикации.

Читается канал `INDICATOR_CHANNEL` (по умолчанию Aurum Research Club).
Распознаётся только шаблон `#GOLD LONG` + «Вход сейчас или» + SL + четыре TP;
подписи к фото тоже читаются. Фиксации связываются по цепочкам ответов,
повторные уведомления не увеличивают максимальный TP. «ФИНАЛЬНЫЙ TP» означает TP4.
GOLD/XAUUSD и GER40/GERMANY40/DE40 считаются одинаковыми инструментами.

Каждый TPn даёт n% полной позиции, первоначальный SL — −1%. Суммируются
проценты от фиксированного депозита, без капитализации. Семь стратегий:
полная фиксация на TP1, TP2, TP3 или TP4; 25/25/25/25; 40/20/20/20; 50/50 на TP1/TP2.
Не достигшие своей цели части теряют свою долю 1%; рекомендации о БУ игнорируются.
В 22:00 Europe/Moscow все сделки дня считаются закрытыми: недостигнутый остаток
по SL. Более поздние уведомления не меняют итог. До 22:00 в суммы включены только
сделки с явным SL или TP4, остальные показаны как ожидающие. Автоматический
дневной отчёт приходит админу в личку в 22:00; при запуске позже — после загрузки истории.
Период выбирается по дате публикации сигнала в МСК.

При запуске вся доступная история перечитывается в независимую таблицу
`indicator_messages`; новые сообщения и правки обновляют её сразу. На другие
правила пересылки и их статистику функция не влияет.

Проверка: `python3 -m unittest discover -s tests -p test_indicator.py`.

В меню индикатора и под каждым отчётом можно выбрать «Все инструменты», «Золото»,
«Германия» или другой инструмент из истории. Переключение под отчётом сохраняет
период; список сигналов и его страницы используют тот же фильтр. Выбор сохраняется
для чата администратора и применяется к последующим запросам и произвольным датам.
Автоматический дневной отчёт по-прежнему содержит все инструменты.
